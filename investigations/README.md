# Blind SOC Investigations

Учебные расследования оповещений по синтетическим сценариям. В отличие от Hands-on Labs, активность здесь не генерировалась в собственной среде: исходные события взяты из готового датасета, а вердикт сформирован по этим событиям без опоры на эталонный ответ. Это не реальные корпоративные инциденты и не события Wazuh-лаборатории; лабораторные кейсы перечислены в [основном README](../README.md#лабораторные-кейсы).

| Кейс | Сценарий | Навыки | Вердикт |
| --- | --- | --- | --- |
| [TRIAGE-01](TRIAGE-01-mass-file-modification/README.md) | Mass File Modification | Анализ ложных срабатываний, анализ процессов | Закрытие отложено до подтверждения легитимного резервного копирования |
| [TRIAGE-02](TRIAGE-02-password-spraying/README.md) | Password Spraying | Анализ аутентификации, первичный разбор инцидента | Подозрительная активность; высокий приоритет и эскалация |
| [TRIAGE-03](TRIAGE-03-oauth-consent/README.md) | OAuth Consent Abuse | Безопасность облачных сервисов, OAuth-разрешения, оценка рисков | True Positive — Policy Violation; High |

## Исходные данные

Для расследований использованы записи `INC-020`, `INC-030` и `INC-090` из публичного [AI Security Reasoning Benchmark](https://github.com/garrett-williams/ai-security-reasoning-benchmark).

Исходные записи сохранены без изменений в `evidence/original-events.jsonl` каждого кейса. Эталонные ответы не использовались при первоначальном анализе и представлены отдельно для сравнения результатов.

## Методика и ограничения

Каждый сценарий — синтетическая запись из трёх-четырёх событий, а не полный набор корпоративной телеметрии. Учебные адреса, имена и временные метки сохранены как в датасете, репутационные проверки синтетических IP не проводились. Отчёты составлены по заметкам учебных разборов, полные стенограммы анализа не приложены.

Если нужной телеметрии в записи нет, проверка отмечена как незавершённая. Рекомендации не выдаются за выполненные действия.

Уровень уверенности отражает степень обоснованности выводов на основании доступных событий. Он не является вероятностью компрометации и не копируется из эталонного поля `confidence_label`. Если критичность не была определена при первоначальном разборе, она не назначается задним числом.
